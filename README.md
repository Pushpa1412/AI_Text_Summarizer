# 🧠 AI Text Summarizer

An interactive AI-powered text summarization web application built using
Python, Hugging Face Transformers, PyTorch, and Streamlit.

## 🌐 Live Demo

👉 [Try the AI Text Summarizer](https://aitextsummarizer-jddwjogad6ewsxtctubsz.streamlit.app/)

## 🚀 Features

- Summarizes long text automatically
- Uses Facebook BART Large CNN
- Simple and responsive Streamlit interface
- Real-time AI-generated summaries
- Easy to use
- Deployed on Streamlit Community Cloud
